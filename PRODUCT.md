# Product

## Register

product

## Users

Solo developers and small self-hosters who run homelab on their own machine or server. They maintain several apps, workers, domains, servers, and scheduled jobs, and need one quiet place to see what is running, what changed, what broke, and what needs attention.

## Product Purpose

homelab is a tiny observability platform for personal and small-project operations. It gives users a private operational dashboard for project health, uptime checks, cron heartbeats, deploy markers, alerts, TLS expiration, server state, and timeline context. Success means a user can open the app and quickly understand whether anything needs action, without checking multiple terminals, provider dashboards, or config files.

## Brand Personality

Minimal, technical, calm. The interface should feel like a focused local tool: pragmatic, scannable, and efficient rather than promotional or decorative.

## Anti-references

This should not look like a marketing site, SaaS landing page, public status-page brochure, enterprise observability command center, or neon terminal cosplay. Avoid oversized hero sections, decorative metrics, over-styled dashboard chrome, playful branding, heavy gradients, and dense visual noise that makes the user hunt for the real problem.

## Design Principles

1. Lead with operational truth: make current health, active risks, and recent changes immediately visible.
2. Keep the interface quiet until something needs attention.
3. Use familiar product patterns so the user can act without learning a new visual language.
4. Treat warnings and failures as first-class information, not decorative status color.
5. Prefer local, practical workflows over hosted-platform polish.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Status must not rely on color alone; pair color with labels, icons, or clear copy. Motion should be limited to state feedback and respect reduced-motion preferences. The interface should remain legible in long-running, low-attention operational contexts.
